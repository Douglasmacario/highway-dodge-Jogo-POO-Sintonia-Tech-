# Highway Dodge 🚗

Highway Dodge é um jogo 2D desenvolvido em JavaScript, no qual o jogador controla um carro e precisa desviar dos veículos que aparecem na rodovia, tentando sobreviver o máximo possível e bater seu recorde.

O projeto foi desenvolvido para a disciplina de **Programação Orientada a Objetos (POO)**.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API

## Funcionalidades

- Movimentação do carro pelas teclas WASD ou setas.
- Trânsito com veículos em diferentes faixas e sentidos.
- Aparição de até 3 carros simultaneamente.
- Sistema de colisão e pontuação.
- Dificuldade progressiva.
- Bônus de 5 pontos por ultrapassagens arriscadas.
- Garagem com carros desbloqueáveis.
- Recorde salvo no navegador.
- Sistema de pausa e reinício.
- Efeitos sonoros.

## Conceitos de POO

O projeto utiliza conceitos de Programação Orientada a Objetos, como:

- **Classes e objetos:** representação dos veículos e do jogo.
- **Herança:** classes `CarroJogador` e `CarroInimigo` derivadas da classe `Carro`.
- **Encapsulamento:** organização de atributos e métodos nas classes.
- **Polimorfismo:** comportamentos específicos para diferentes tipos de carros.
- **Abstração:** separação das responsabilidades entre as classes.

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta `highway-dodge`.
3. Execute o arquivo `iniciar.bat` (Windows, com Python instalado).

Também é possível executar o `index.html` utilizando a extensão **Live Server** do VS Code.

## Controles

| Tecla | Ação |
|---|---|
| W / ↑ | Mover para cima |
| S / ↓ | Mover para baixo |
| A / ← | Mover para esquerda |
| D / → | Mover para direita |
| P / Esc | Pausar ou continuar |

## Objetivo

Desviar dos veículos, acumular pontos, realizar ultrapassagens arriscadas e desbloquear novos carros conforme o recorde aumenta.
